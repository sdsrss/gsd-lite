## 决策与进展
- @hono/node-server 的 override 从 `^1.19.14` 改成 `^2.1.3`：漏洞范围内没有修复过的 1.x，SDK 接受 `^1.19.9 || ^2.0.5`。
  另外三条 override 的下限也提到修复版本，因为 npm 包里没有 lockfile，安装时读的是 package.json。
- D#552 只改 CLI 路径（`checkForUpdate({ fromCli })`）。钩子路径不变，插件装在 project scope 时的判断也不受影响。
- `npm trust list gsd-lite` 需要 OTP（EOTP），本地读不到 npmjs.com 上的配置，所以打 tag 前要用户确认。
- 2026-11-01 用户确认：npmjs.com 上 gsd-lite 的 trusted publisher 已配置（本地 `npm trust list` 需要 OTP，无法自查）。
- 0.20.0 已在本地分支准备好、未推送：`ci/action-gh-release-v3`（bc57479，action-gh-release v3.0.3，Node 24 运行时）、`feat/node22-floor`（52203ab，engines >=22，CI 矩阵 [22, 24]）。等 0.19.1 发布后再开 PR。
